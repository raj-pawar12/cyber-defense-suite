# Safe browsing

## Reading a web address
The real site is the registered domain just before the first single slash. In https://paypal.com.secure-login.xyz/verify the real domain is secure-login.xyz, not paypal.com. Anything before an @ sign in a link is ignored by browsers.

## HTTPS and the padlock
HTTPS means the connection between you and the site is encrypted. It does not mean the site is honest, because criminals can get HTTPS certificates too. Check the domain, not just the padlock.

## Good habits
Type important addresses yourself or use bookmarks. Keep the browser updated. Install few extensions and only from official stores. Be cautious with downloads and with pop-ups that claim your device is infected. Log out of shared computers. Use a separate browser profile for banking if you like.
