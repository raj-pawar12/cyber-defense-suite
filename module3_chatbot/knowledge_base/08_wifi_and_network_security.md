# Wi-Fi and network security

## Home network
Change the default router admin password. Use WPA3 if available, otherwise WPA2 with a long passphrase. Turn off WPS. Keep router firmware updated. Use a guest network for visitors and smart devices.

## Public Wi-Fi
Anyone on the same network may be able to watch or tamper with traffic if sites do not use HTTPS. Fake hotspots with familiar names also exist. Avoid banking on public Wi-Fi, or use your mobile data. A VPN protects traffic from the local network, but it does not make you anonymous and you must trust the VPN provider.

## Basic tools
A firewall filters traffic by rules. Network segmentation separates systems so a breach in one area does not reach all. An intrusion detection system watches for suspicious patterns. DNS filtering can block known malicious domains.
