# Ransomware

## How it works
Ransomware gets in through phishing emails, weak remote-access passwords or unpatched software. It encrypts files and shows a message demanding payment. Some groups also steal data first and threaten to publish it, which is called double extortion.

## Prevention
Keep offline or separate backups and test restoring them. Patch software quickly. Use MFA on remote access and email. Block macros from unknown documents. Limit user rights so one infected account cannot reach everything.

## If you are hit
Disconnect the device from the network and Wi-Fi straight away so it cannot spread. Do not switch off if you are unsure, but isolate it and ask a professional. Take photos of the ransom note. Report the incident to the organisation's security team and to the authorities. Paying is generally discouraged because it funds crime and does not guarantee the files come back. Restore from clean backups after the infection has been removed.
