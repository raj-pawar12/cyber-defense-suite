# Passwords, password managers and multi-factor authentication

## Strong passwords
Length matters more than tricks. Use a passphrase of four or more unrelated words, or a random password of 14 or more characters. Never reuse a password between sites, because when one site leaks, attackers try the same password everywhere (credential stuffing). Avoid names, birthdays and keyboard patterns.

## Password managers
A password manager creates and stores a different strong password for every account. You remember one strong master password. It also warns you when a site address does not match, which helps against phishing.

## Multi-factor authentication
MFA adds a second proof besides the password. Authenticator apps and hardware security keys are stronger than SMS codes, because SIM-swap attacks and message interception can defeat SMS. Passkeys replace passwords with cryptographic keys stored on your device and are resistant to phishing.

## Checking for leaks
Services such as Have I Been Pwned let you check whether an email address appeared in a known data breach. If it did, change that password and any copies of it.
