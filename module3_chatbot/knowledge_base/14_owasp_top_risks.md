# Web application risks (OWASP Top 10 themes)

## Main categories
Broken access control lets users do things they should not. Cryptographic failures expose sensitive data. Injection, such as SQL injection, lets attackers send commands through input. Insecure design means security was not planned. Security misconfiguration includes default passwords and open cloud storage. Vulnerable and outdated components bring known bugs. Identification and authentication failures cover weak logins and session handling. Software and data integrity failures include untrusted updates. Security logging and monitoring failures delay detection. Server-side request forgery makes a server fetch attacker-chosen addresses.

## How to use this list
It is an awareness list published by the OWASP community and updated every few years. Developers use it as a checklist when reviewing an application, and students can practise safely on deliberately vulnerable apps such as OWASP Juice Shop.
