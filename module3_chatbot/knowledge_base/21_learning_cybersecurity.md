# Learning cybersecurity and careers

## Where to start
Learn networking basics, Linux, and one programming language such as Python. Understand how the web works: HTTP, cookies, DNS and TLS. Then pick a direction: defensive work (security operations, incident response), offensive testing (penetration testing), application security, or governance and risk.

## Practice legally
Use deliberately vulnerable labs and learning platforms, capture-the-flag competitions, and your own home lab. Never test systems without permission. Bug bounty programmes allow testing within published rules.

## Certifications and projects
Entry-level certificates such as CompTIA Security+ help with fundamentals, and many students also build portfolio projects like a phishing detector, a log analyser or a secure web app. Write up what you built, how you tested it and what you would improve. Employers value clear explanations and honest limitations.
